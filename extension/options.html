Real input

Pages such as Miro ignore clicks and keys that come from a script. Real input sends them the way a mouse and keyboard would. On Windows it needs nothing else: the bridge hands them to this Firefox window directly, your own pointer stays where it is, and the tab comes to the front of its window first. Elsewhere it goes through Firefox's remote control (WebDriver BiDi), which needs Firefox started with --remote-debugging-port=PORT; while that is on, every page can tell the browser is remote controlled (navigator.webdriver), and other programs on this computer can drive Firefox through that port too.
